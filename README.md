# Assessment 1: Securing the IoT

This repository contains my work for **Assessment 1 of the Securing the IoT**.

Here is what you will find in this repository:

- **Private Dataset** – My own running records collected from my previous sessions.
- **Public Dataset** – Running data collected from a public source, used for reference and comparison.
- **Machine Learning Code** – The Python code used to train the model and predict future running times.
- **Results** – The predictions and comparisons between the model's estimates and my actual running times.

## Project Goal

The goal of this project is to see how well Machine Learning can learn from my running progress and predict my future performance. I will compare the predicted times with my actual running results to see how accurate the model is.
